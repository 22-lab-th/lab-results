# ชุดทดสอบเรียก tool 40 ข้อ (Saluki กับ Qwen3.8 Q8)

ไฟล์ชุดนี้มาจากคลิปที่เราลอง Underdog Saluki 27B ไฟล์ IQ2 ขนาด 7.90 GB เทียบกับ Qwen3.8-27B Q8_0 และ Qwen3.6-27B Q5_K_M บน Mac M5 Max เครื่องเดียว ใช้ llama.cpp รันในเครื่อง ไม่มีค่า API

## ผลของเรา (40 ข้อ × 3 รอบ = 120 ครั้งต่อโมเดล)

| | Saluki IQ2 | Qwen3.8 Q8_0 | Qwen3.6 Q5_K_M |
|---|---|---|---|
| รวม | 102/120 (85.0%) | 111/120 (92.5%) | 99/120 (82.5%) |
| เลือก tool / ซ้อนข้อมูล / หลายคำสั่ง / ต่อเนื่อง | 24/24 ทุกหมวด | 24/24 ทุกหมวด | 24/24 ทุกหมวด |
| ถามกลับเมื่อข้อมูลไม่ครบ | 6/24 | 15/24 | 3/24 |
| โจทย์ภาษาไทย | 24/30 | 27/30 | 24/30 |
| ความเร็วสร้างคำตอบ | 24.55 tok/s | 13.68 tok/s | 16.20 tok/s |

เกณฑ์ที่ตั้งไว้ก่อนรันคือ Saluki ต้องตามตัวเทียบไม่เกิน 5 จุด ผลจริงตาม 7.50 จุด จึงไม่ผ่าน Q8 ไม่ใช่ตัวเต็ม BF16 คำอ้างของผู้สร้างที่เทียบกับตัวเต็มจึงยังไม่ได้ทดสอบ

โจทย์ทั้งหมดเราเขียนขึ้นเอง ไม่ใช่ BFCL ทุกข้อส่งเครื่องมือ 24 ตัวพร้อมกัน และไม่มีการเรียกเครื่องมือจริง หมวดถามกลับตรวจด้วย regex จึงอาจตัดสินคำตอบที่ถามกลับด้วยถ้อยคำอื่นว่าไม่ผ่าน

## ลองกับโมเดลของคุณ

ต้องมี Python 3 อย่างเดียว ไม่ต้อง pip install อะไร เปิดเซิร์ฟเวอร์ที่รับคำขอแบบ OpenAI ไว้ก่อน เช่น llama.cpp

```sh
llama-server -m your-model.gguf --jinja -c 8192 -ngl 99 -fa on --port 8080 \
  --reasoning off --chat-template-kwargs '{"enable_thinking":false}'
python3 try_suite.py --url http://127.0.0.1:8080
```

ถ้าอยากได้ค่าตั้งเดียวกับคลิป ให้เพิ่ม `--chat-template-file chat-template.jinja` ซึ่งเป็นแม่แบบสนทนาของ Saluki ที่เราใช้กับทุกโมเดล ใช้ `--repeats 3` ถ้าจะรันสามรอบเหมือนเรา หรือ `--limit 5` ถ้าแค่อยากลองก่อน ผลแต่ละข้อจะอยู่ใน `my-results.jsonl`

สคริปต์นี้ย่อจากตัวรันในแลบให้ชี้ไปที่เซิร์ฟเวอร์ที่เปิดอยู่แล้ว ส่วนให้คะแนนใช้ `score.py` ตัวเดียวกัน เราลองรันสคริปต์นี้กับ Saluki หนึ่งรอบ ได้ 34/40 และพลาดข้อเดียวกับรอบแรกของแลบ คือ h33 h34 h35 h36 h39 h40

## ไฟล์

- `tasks-hard.json` โจทย์ 40 ข้อ พร้อมเครื่องมือและคำตอบที่ถูก
- `system-hard.txt` system prompt ที่ใช้ทุกข้อ
- `chat-template.jinja` แม่แบบสนทนาของ Saluki
- `score.py` ตัวให้คะแนน ชื่อเครื่องมือและค่าทุกช่องต้องตรง
- `try_suite.py` ตัวรันสำหรับเซิร์ฟเวอร์ของคุณ
- `protocol.md` กติกาที่ล็อกไว้ก่อนรัน (ภาษาอังกฤษ)
- `summary-hard.json` สรุปผลของเรา
- `results-<model>.jsonl` คำขอและคำตอบดิบทุกครั้ง เปลี่ยน path ในเครื่องเป็น `~/models/`
- `rescored-<model>.jsonl` คะแนนสุดท้ายของแต่ละข้อ
